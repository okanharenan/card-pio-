O projeto **BBQ BRO** foi desenvolvido como projeto estudantil com o objetivo de praticar conceitos de:

- Estruturação de interfaces
- HTML semântico
- CSS moderno
- Responsividade
- JavaScript
- Manipulação do DOM

Além disso, o sistema também foi criado para compor portfólio profissional na área de desenvolvimento web.
